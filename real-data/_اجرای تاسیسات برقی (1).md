# Summary: `_اجرای تاسیسات برقی (1).xlsx`

## Overview
Daily execution report workbook for the **Electrical Installations Unit (`واحد اجرای تاسیسات برقی`)** of the **Komeil Abad, Shiraz National Housing Project** (executed by **Pey Chin Co.**), covering 215 daily report sheets from `1404/04/11` to `1404/12/07`.

## File Metadata
- **Source File**: `_اجرای تاسیسات برقی (1).xlsx`
- **File Size**: ~5.02 MB (5,016,012 bytes)
- **Total Sheets**: 215 (one sheet per day, named `14040411` through `14041207`)
- **Date Coverage**: `1404/04/11` – `1404/12/07` (note: sheets `14040411`–`14040425` carry header date `1404/03/10` from a copied template, while sheet tab names reflect the actual daily sequence)

## Structure of Each Daily Sheet
1. **Header Metadata**: Company (`شرکت پی چین`), Form Title (`گزارش روزانه واحدهای اجرا`), Project (`پروژه مسکن ملی کمیل آباد شیراز`), Discipline (`اجرای تاسیسات برقی`), Weather Condition, and Date.
2. **Executed Activities Table**:
   - **Execution Group (`گروه اجرایی`)**: Shift, contractor/company crew name (e.g., `رضایی`, `شرکت`), number of master craftsmen (`استاد کار`) and laborers (`کارگر`).
   - **Location (`موقعیت`)**: Block (`بلوک`) and Floor (`طبقه`).
   - **Work Details**: Activity description (`شرح فعالیت` — e.g., ceiling/wall electrical conduit piping, connecting ceiling-to-wall conduits, string pulling, temporary cable troubleshooting), unit (`متر طول`, `مورد`, `واحد`), and quantity (`مقدار`).
3. **Machinery Section (`ماشین‌آلات`)**: Equipment name, active/inactive status, start/end hours, and activity description.
4. **Obstacles & Problems (`موانع و مشکلات`)**: Daily technical or administrative bottlenecks (e.g., pending approval of electrical drawings by the Engineering Organization).
5. **Sign-off**: Execution Supervisor signature (`امضاء سرپرست اجرا`).
