# Summary: `data base shiraz 2 from 14040701 to 140401208.xlsx`

## Overview
Second-period consolidated operations database for the **2,000-Unit National Housing Project in Komeil Abad, Shiraz (پروژه مسکن ملی کمیل‌آباد شیراز)** covering the second half of Persian year 1404 (`1404/07/01` to `1404/12/08`, with template date rows extending to `1404/12/29`). It follows the same 9-sheet relational structure as `data base shiraz (1).xlsx`.
