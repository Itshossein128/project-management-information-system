# ماتریس پوشش پذیرش دسترسی A.6

این ۲۹ حوزه از مسیرهای فعلی کد استخراج شده‌اند؛ ردیف‌های این فایل، نیازمندی جدید یا ۲۹ تست موفق نیستند. شاهد هر ردیف فقط به همان آزمون منتخب محدود است. برای A.6.2 باید از روی URLهای فعال، تک‌تک عملیات قابل اجرا زیر هر حوزه استخراج و نتیجهٔ مثبت/منفی ثبت شود. عملیات ناموجود «غیرقابل اعمال» با دلیل ثبت شود، نه اینکه مجاز فرض شود.

در هر حوزه: عضو مجاز، عضو فاقد مجوز، غیرعضو، عضو غیرفعال، مشاهده‌گر، چندنقشی، grant/deny، مدیر پروژه و استثنای سازمانی؛ دو پروژه مستقل؛ API مستقیم و فرم؛ شناسه متعلق به پروژه دیگر؛ مشاهده/ثبت/ویرایش/حذف/تأیید/ورود/خروج فایل و عملیات پس‌زمینهٔ موجود بررسی شوند. ساخت منطق تجاری جدید جزء این ماتریس نیست.
