# راهنمای اسناد ماژول تصمیم‌یار Velora

این راهنما مسیر مطالعه و مرجع هر موضوع را در مجموعه اسناد تصمیم‌یار مشخص می‌کند. هر سند یک مسئولیت دارد؛ قواعد مشترک یک‌بار تعریف شده‌اند و اسناد روش‌ها به همان قواعد ارجاع می‌دهند.

مبنای مجموعه، [سند اصلی](<../document (10).docx>) با تاریخ ۱۸ مهر ۱۴۰۵ است. این اسناد بیانگر طراحی موردنظر هستند؛ وجود آن‌ها به معنی پیاده‌سازی یا تأیید رفتار فعلی نرم‌افزار نیست.

## مسیر مطالعه

برای شناخت محصول، دامنه ماژول را بخوانید. برای طراحی فرم، قرارداد ورودی و سند روش انتخاب‌شده را دنبال کنید. برای توسعه، پس از این دو مرجع، چرخه اجرا، مرجع کد و [فهرست مؤلفه‌ها](../decision-support-component-inventory.md) را بخوانید. برای پذیرش، معیارهای پذیرش و موارد باز در سند بازبینی را بررسی کنید.

## قواعد نگهداری مجموعه

- تعریف هر قاعده در سند مسئول آن تغییر می‌کند؛ اسناد دیگر به آن لینک می‌دهند.
- فرمول‌ها و خروجی اختصاصی هر روش در سند همان روش نگهداری می‌شوند.
- معیارهای پذیرش قواعد جدید تعریف نمی‌کنند؛ بررسی قواعد مرجع را مشخص می‌کنند.
- نمونه کد مرجع رفتار همان نمونه است؛ اختلاف آن با طراحی در سند بازبینی ثبت می‌شود.
- ابهام حل‌نشده با فرض پنهان جایگزین نمی‌شود؛ در سند بازبینی باقی می‌ماند.
